# Atenea en El Dorado

Videojuego 2D desarrollado como proyecto final universitario.

## Estado del proyecto

Actualmente el proyecto se encuentra en **Momento I**, correspondiente a la definición inicial de la propuesta del videojuego.

## Documentación

La documentación del proyecto se gestiona mediante **Obsidian** dentro de la carpeta `docs/`.

### Documentación académica

- [Momento I](docs/academic/Momento-I.md)

## Estructura del proyecto

```text
proyecto-final/
├── docs/                  # Documentación y Vault de Obsidian
│   ├── academic/         # Entregas académicas
│   ├── decisions/        # Decisiones del proyecto
│   ├── planning/         # Planificación
│   ├── product/          # Diseño y visión del videojuego
│   ├── inbox/            # Ideas pendientes de organizar
│   └── .obsidian/        # Configuración del Vault
│
├── src/                  # Código fuente C++
├── include/              # Archivos de cabecera C++
├── assets/               # Recursos del videojuego
├── README.md
└── .gitignore
